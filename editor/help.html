打开与关闭

在网站文件夹中双击「打开 Nabla 编辑器.command」，浏览器将打开 http://127.0.0.1:6178/admin/。此服务只监听这台电脑。编辑器启动窗口需保持打开；关闭窗口会停止本地服务。网站本身不提供 /admin/。

改文字、图片与链接

  1. 在「页面内容」中选择页面。
  2. 展开对应章节，修改英文或中文字段，右侧即时预览。两种语言需要分别填写。
  3. 切换「图片」可上传替换图片及填写图片说明；切换「链接」可修改联系邮箱的 mailto 地址或其他链接。
  4. 标题、简介等在不同页面出现时，需要分别修改。「全站页眉与页脚」的修改则会应用于相应语言的所有页面。
  5. 点击「恢复原文」，清除该字段覆盖，恢复网站源模板中的原始文字。

写 Nabla 社论

「Nabla 社论 → 新建社论」填写中英文标题、署名、发表日期、英文摘要与中文正文。英文全文选填；暂不提供时，英文页面会链接到中文原文。正文支持空行分段、# 小标题、**粗体**、链接及图片。设为「公开发布」后再发布到网站。

现有创刊说明可从左侧入口进入页面表单编辑。已发表文章保留首次发表日期，发布更正时须填写说明；新观点请另写文章，避免覆盖历史论述。首次发表的文章网址和日期固定。

本机草稿与图片

文字、文章草稿与待上传图片会自动保存在本机的 .local-studio 文件夹（不进入 GitHub 仓库）。也可以点击「保存到电脑」或按 ⌘S。重新打开编辑器会恢复上次草稿。需要单独备份时，使用「导出草稿备份」保存 JSON 文件。备份不含发布令牌，可通过「导入草稿」恢复。源网站更新后，旧草稿会要求手动合并，以防覆盖新内容。

网站仓库公开。保存在本机的草稿不会自动上传；点击发布时，页面修改、上传图片与设为「公开发布」的社论会进入公开仓库。仍为草稿的社论只保留在本机，不会上传；尚未准备公开的图片请勿随其他修改发布。

连接 GitHub 并发布

  1. 点击「连接 GitHub」，按说明创建细粒度令牌（fine-grained token）。仓库只选择 yongqi-yuan/nabla-lab，Contents 设为 Read and write；Actions 设为 Read-only 以查看部署进度。
  2. 令牌只粘贴到后台密码框，不要发到聊天。它仅在当前标签页内存中使用，刷新或关闭后需重新连接。
  3. 点击「预览并发布」，检查变更列表，填写修改说明。已发表社论的修改还需填写更正说明。
  4. 点击确认后，所有内容作为一次 GitHub 提交保存，网站自动构建部署。后台会显示部署进度；也可打开 GitHub Actions 检查。

如果有人同时修改内容，发布会停止并保留草稿。请先导出备份，刷新载入新版本后再合并。若已提交但部署失败，修改仍在 GitHub，可以在部署记录中检查原因。

恢复误改

每次发布有对应的 GitHub 修改记录。单个字段可在表单中恢复原文后重新发布；需要撤销整次修改时，可在 GitHub 中恢复对应内容提交，或请维护者协助。无需重新制作整个网站。
